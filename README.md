# Typed Data Dashboard (Module 7)

Vite + React + TypeScript dashboard.

## Features
- TypeScript interfaces for component props (`src/types.ts`)
- TanStack Query fetches posts, with loading and error fallbacks
- Zustand store for a global dark/light theme toggle
- `useRef` + `useEffect` auto-focus the search input
- React Testing Library test for `PostCard`

## Run
npm install
npm run dev

## Test
npm test
